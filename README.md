# Dental Case Library · 我的病例书柜

可重复调用的艺术牙科病例书 Skill，用于个人收藏和同行交流。

## 下载与安装

完整源码在 dental-case-library-v0.1.0.zip 中。下载并解压本仓库中的 ZIP，安装其中的 dental-case-library 文件夹，读取其 SKILL.md。请勿只安装仓库首页。ZIP 包含完整 SKILL.md、references、scripts、agents、本地翻页模板和全部许可证。

WorkBuddy：下载解压后按宿主支持的方式安装 Skill。豆包：可使用 PORTABLE_PROMPT.md，完整书柜需要本地文件、Python 和 HTML 能力。两个平台尚未实测。

每本统一元素、跨页构图变化，保留临床核心原图，克制融合外围；自动归入紧密错落的书柜。艺术生成需要宿主图片编辑工具，导入脚本本身不生成艺术。只处理已脱敏素材，不猜测临床阶段。

完整包已通过本地导入、翻页和归档测试，公开下载已验证与本地包字节一致。代码 MIT，StPageFlip 与上游 create-photo-flipbook-ui 许可、署名保留在源码包。不含真实病例或患者素材。
