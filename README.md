# Dental Case Library · 我的病例书柜

## 最新版本 v0.2.0

下载本仓库中的 dental-case-library-v0.2.0.zip，解压并安装其中 dental-case-library 文件夹，读取 SKILL.md。完整脚本、资源、许可证均在 ZIP 内。

v0.1 普通相册降级流程已废弃，请勿继续使用。v0.2 导入仅建草稿，实际艺术融合与原图保护完成后才允许归档，不能用逐页贴照片冒充完成品；不固定筛选六张，不重启已经确认的审美设计。

同一本统一元素，跨页构图变化；不同书可采用国画、油画、摄影、赛博朋克等风格。用于自己收藏与同行交流。

宿主必须具备看图和图像编辑能力才能完成艺术制作；否则明确报告缺口，不降级交付普通相册。WorkBuddy v0.1 安装运行测试发现未复现艺术效果，v0.2 的完整视觉流程尚未跨平台验收。豆包同样未实测。

本地测试通过：不含艺术的草稿不能入柜，合成本地图层可完成归档，路径越界与同名覆盖会被拒绝，原文件保留。公开包不包含真实患者素材。
